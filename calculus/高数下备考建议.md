# 高数下备考建议

> 来源：`“向量机与多元函数基础解析”-转文本结果.txt`。转写质量较差，以下内容已经按高等数学语境做了必要校正和推断。

## 一、转写纠错判断

- “向量机”大概率是“向量积”。
- “高速公式”大概率是“高斯公式”。
- “隔离公式 / 故事公式”大概率是“格林公式”。
- “父母 / 干扰素”多半对应“偏导数 / 全微分”。
- “收入量 / 熟练 / 发生”多半对应“收敛 / 发散”。
- “抽样函数”多半对应“多元函数”。

## 二、总体考试范围

本次讲话实际覆盖范围不止“向量与多元函数”，而是第八章到第十二章：

1. 第八章：空间解析几何与向量代数。
2. 第九章：多元函数微分法及其应用。
3. 第十章：重积分。
4. 第十一章：曲线积分与曲面积分。
5. 第十二章：无穷级数。

老师多次强调：第一节、第二节通常是每章最基础内容，定义、定理、基本公式不能只会算题而不背条件。

## 三、最高优先级内容

### 1. 二元函数极值

这是最明确的重点之一。老师原话意思接近“每年都考”“几乎都要考”。

必须掌握：

- 极大值、极小值、极值点的定义。
- 求驻点：令 `f_x = 0, f_y = 0`。
- 计算二阶偏导：`A = f_xx, B = f_xy, C = f_yy`。
- 判别式：`D = AC - B^2`。
- `D > 0, A > 0`：极小值。
- `D > 0, A < 0`：极大值。
- `D < 0`：不是极值。
- `D = 0`：不能判定。

注意混合偏导：在连续条件下 `f_xy = f_yx`。

### 2. 条件极值

必须区分：

- 目标函数是什么。
- 限制条件是什么。
- 用拉格朗日乘数法建立方程组。

老师说这部分“必须掌握”，并且提到上课讲过两个问题、书上有、作业也留过。因此相关课堂例题和作业题要重点复盘。

### 3. 方向导数与梯度

老师明确强调“非常重要”“必须掌握”。

必须掌握：

- 方向导数定义（100页）。
- 梯度定义。
- 方向导数计算公式，尤其老师点到的公式 `7-2`。
- 书上 103 页例题必须看，老师专门翻到这一页。
- 方向导数与梯度的关系：
  - 沿梯度方向，方向导数最大，值为 `|grad f|`。
  - 沿梯度反方向，方向导数最小，值为 `-|grad f|`。
  - 与梯度垂直方向，方向导数为 `0`。
- 求“增加最快方向”“减少最快方向”“变化率为零的方向”。

答题要注意符号和格式。老师专门提醒“书写要规范”。

### 4. 重积分

第十章是积分大头。老师说“肯定会碰到”。

必须掌握：

- 二重积分概念、性质、计算方法。
- X 型区域、Y 型区域的积分限写法（137 页 `二-1'`、138 页 `二-2'`）。
- 极坐标变换（142 页 `二-4` 必须记住）。
- 三重积分在考试范围内。
- **截面法（必须掌握）**：老师多次强调，截面法是三重积分的核心方法。
- 投影法 / 柱坐标思想。
- 能画出大致区域图。

老师提到“我们会有一道题目这一块”，所以二重积分或三重积分计算题概率很高。

**重积分应用**：曲面面积公式在 163 页（根号下偏导平方和的积分），老师说“需要熟练掌握”，在考试范围内。

### 5. 曲线积分（§11.1-11.2）

格林公式之前的基础，必须先会算：

- **第一类曲线积分（对弧长）**：老师说"最简单的一个"。182 页定理，公式 `一-1`，计算核心是把弧长微元 `ds` 转为参数 `dt`。
- **第二类曲线积分（对坐标）**：189 页定理。**注意方向**（有向曲线），参数增大的方向对应正向。

### 6. 格林公式

第十一章第三节是重点。

必须掌握：

- 格林公式的使用条件：区域边界光滑或分段光滑，曲线取正向，`P, Q` 有连续偏导。
- 把第二类曲线积分转化为二重积分。
- 老师说考试会是“直来直去”的类型，不会太绕。
- 用格林公式时要写明“根据格林公式”，不要只写符号。

还要掌握路径无关：

- 积分与路径无关的条件。
- 只与起点、终点有关。
- 可以选特殊折线路径计算。
- 相关作业是 **208 页第六大题**，被老师直接点名。
- **全微分求原函数**：已知 `du = Pdx + Qdy`，求原函数 `u(x,y)`。公式参考书上 **三-6**。老师说可以用积分与路径无关的方法（选特殊折线），也可以用偏积分法。

### 7. 曲面积分与高斯公式

第一类曲面积分在考试范围内，比较基础。第二类曲面积分较难，但与高斯公式相关，不能跳过。

必须掌握：

- 第一类曲面积分公式，老师点到 `4-2`。
- 会找曲面在坐标面上的投影区域。
- 第二类曲面积分的定义（216 页）、方向、投影、符号问题。
- 公式 `5-3, 5-3', 5-4, 5-5`。
- 例题一、例题二要会。

高斯公式：

- 老师说“几乎每年都会有”。
- 要记条件、方向、封闭曲面。
- 会把第二类曲面积分转成三重积分。
- 用公式前要写“根据高斯公式”。
- 典型区域可能是圆柱、平面 `z = 3`、`x^2 + y^2 <= 1` 这类。

### 8. 级数

第十二章内容在后半段重点讲了不少。

必须掌握：

- 数项级数收敛、发散定义（242 页）。
- 收敛的必要条件：通项趋于 0（243 页 `一-1`）。反过来，若通项极限不为 0，则级数发散。
- 调和级数发散（务必记住）。
- 正项级数判别法：比较判别法、极限比较判别法、比值判别法、根值判别法。
- `p` 级数：`p > 1` 收敛，`p <= 1` 发散（公式 `二-2`）。
- 交错级数：莱布尼茨定理（254 页，必须记住）。
- 绝对收敛与条件收敛的概念必须区分清楚。
- 判断绝对收敛时先加绝对值。
- 幂级数的收敛半径、收敛区间、收敛域（注意：区间 vs 域不是一回事）。
- 函数展开成幂级数：直接法、间接法、变量替换。老师专门提到 **275 页第五行**的公式，要自己推导一遍。

老师提到例 1 到例 6，尤其例 6 “很经典”，建议重点做。

## 四、其他要复习但优先级略低的内容

### 1. 空间解析几何与向量

重点：

- 数量积、向量积。
- 三角形面积用向量积。
- 空间直线的一般方程、对称式、参数式。
- 直线可以表示为两个平面的交线。
- 过直线作平面，且与已知平面垂直。
- 直线在平面上的投影。
- 距离问题。

曲面识别：

- 圆锥面。
- 旋转曲面。
- 椭球面。
- 常见二次曲面。
- 空间曲线的一般方程、参数方程。

### 2. 多元函数基础

重点：

- 二元函数极限与连续（59 页起）。
- 证明极限不存在，常用不同路径法（老师原话："考察函数的极限是不存在的，怎么证明函数没有极限？有不同路径"）。
- 有界闭区域上连续函数的最大值、最小值定理。
- 偏导数、高阶偏导数。
- 混合偏导相等条件。

### 3. 全微分

重点：

- 全微分定义（70 页）。
- 可微的必要条件（定理一）、充分条件（定理二）。
- 老师提到 **72 页**内容一定要记，**书上两个例题**（推测是 72-73 页附近）非常重要。
- 老师原话："最难的就是这些定理的定义，具体求的话是非常简单"。

老师强调：这部分难点不在计算，而在定义和定理。

### 4. 多元复合函数求导

重点：

- 链式法则：定理一、二、三。
- 书上第一、第二、第三题一定要会。
- 第四类题稍难，但基础做法要掌握。

### 5. 隐函数求导

重点：

- 隐函数存在定理一、二。
- 公式 `5-2`、`5-4` 被点名。
- 典型做法：先求 `F_x, F_y, F_z`，再套公式。
- 复杂理论或证明大概率不考，计算要会。

### 6. 空间曲线、曲面的切线法平面与切平面法线

重点：

- 空间曲线的切线和法平面（93 页，公式 `6-8`）。
- 曲面的切平面和法线（公式 `6-18`）。
- 法向量概念。
- 老师点到公式 `6-8`、`6-18` 一类。
- 后面曲面积分还会用到法向量。

## 五、明确弱化或不考内容

- 重积分的物理应用，如引力等，老师明确说不考。
- 带星号内容多数可以弱化，但级数部分有些“虽然打星号也要掌握”的判别法不能完全跳过。
- 曲线积分、曲面积分里的复杂理论推导不是重点，主要会用公式计算。
- 过难、过偏的综合题概率不高，老师反复说会围绕黑板讲过、作业留过、基础内容出题。

## 七、推荐复习顺序

时间紧的话，按这个顺序刷：

1. 二元函数极值、条件极值。
2. 方向导数与梯度。
3. 二重积分、三重积分、极坐标、柱坐标、积分限、曲面面积。
4. 第一类/第二类曲线积分、格林公式、路径无关、全微分求原函数。
5. 曲面积分（第一类/第二类）、高斯公式。
6. 级数判敛、绝对收敛、条件收敛、幂级数。
7. 空间直线平面、向量积、切平面法线。
8. 多元复合函数求导、隐函数求导、全微分定义与定理。
