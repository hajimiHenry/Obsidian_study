### 第七节 · 方向导数与梯度 ⭐ 非常重要

**22:16** 100 页——方向导数定义。公式七-2（方向导数计算公式，必须会）。

**方向导数与梯度的关系（必须掌握）**：
- 沿梯度方向 → 方向导数最大，值 = |grad f|
- 沿梯度反方向 → 方向导数最小（减少最快），值 = -|grad f|
- 与梯度垂直方向 → 方向导数为 0（变化率为零）

103 页例题必须看（增加最快/减少最快/变化率为零的方向）。书写要规范。

### 第八节 · 多元函数极值 ⭐ 几乎每年都考

**31:01** 二元函数极值定义（极大值、极小值、极值点）。

判定流程：
1. 求驻点：令 f_x = 0, f_y = 0
2. 对每个驻点，计算二阶偏导：A = f_xx, B = f_xy, C = f_yy
3. 行列式 D = AC - B²
   - D > 0, A > 0 → 极小值
   - D > 0, A < 0 → 极大值
   - D < 0 → 不是极值
   - D = 0 → 不能判定

混合偏导连续时 f_xy = f_yx。

**条件极值（拉格朗日乘数法）**：
- 分清目标函数和限制条件
- 建立拉格朗日方程组
- 上课讲了两个问题，书上有，作业也留了——必须掌握

**小结**：第八章、第九章考小题（5 题 × 5 分 = 25 分）。

### 格林公式 ⭐ 重点

**54:59** 第三节重点。

条件：
- 区域边界光滑或分段光滑
- 曲线取正向
- P、Q 有连续偏导数
