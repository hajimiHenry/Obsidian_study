## 8. 章末总复习：做题检查清单 + 考点地图

### 与上一小节关系

前七节把二重积分、三重积分、坐标变换、应用、含参积分全讲完了。这一节是**考前冲刺用的**——把所有内容压缩成可执行的检查清单，做一道题对一遍。

### 学习目标

- 能一眼判断题目属于哪一类问题。
- 能在开始算之前选对坐标、边界和积分元素。
- 能用结果检查法发现自己的常见错误。

---

### 8.1 题型分类（考试出什么）

本章所有题目都在下面五类里：

| 类型 | 标志 | 核心动作 |
|------|------|----------|
| **二重积分计算** | 被积函数和区域都在 $xy$ 平面 | 画图 → 选坐标 → 写限 → 积 |
| **三重积分计算** | 被积函数和空间体在 $xyz$ 空间 | 画图 → 选坐标 → 写三层限 → 积 |
| **应用题** | 问体积/面积/质量/质心/转动惯量/引力 | 元素法：小块贡献 → 积分 |
| **含参积分** | 积分号里有参数，或积分限含变量 | 求导/换序/莱布尼茨 |
| **理论/证明题** | 估值、比较、中值定理、对称性 | 用性质，不算 |

---

### 8.2 做题标准流程

#### 二重积分

```
画区域
  ↓
看区域形状 + 被积函数
  ├── 圆/环/扇形 或 含 x²+y² → 极坐标
  ├── 椭圆 → 广义极坐标
  ├── 出现 x+y、y/x 等组合 → 一般换元
  └── 一般情况 → 直角坐标
  ↓
选扫描方向（X型 vs Y型）
  ↓
写范围（内层限可含外层变量）
  ↓
带面积元素（直角 dxdy，极坐标 ρdρdθ，换元 |J|dudv）
  ↓
先看对称性！奇函数项直接消掉
  ↓
计算（内层→外层）
```

#### 三重积分

```
画空间体
  ↓
看对称性
  ├── 绕 z 轴对称 → 柱面坐标 (ρdρdθdz)
  ├── 球对称 → 球面坐标 (r²sinφ drdφdθ)
  └── 一般 → 直角坐标
  ↓
选投影方向 或 截面法
  ↓
写三层范围（最内层限可含外面变量）
  ↓
带体积元素
  ↓
计算
```

---

### 8.3 坐标与积分元素速查

| 坐标系 | 变换公式 | 面积/体积元素 |
|--------|----------|--------------|
| 直角（二重） | $x,y$ | $dx\,dy$ |
| 极坐标 | $x=\rho\cos\theta,\ y=\rho\sin\theta$ | $\boxed{\rho\,d\rho\,d\theta}$ |
| 一般换元 | $x=x(u,v),\ y=y(u,v)$ | $\boxed{\|J\|\,du\,dv}$ |
| 直角（三重） | $x,y,z$ | $dx\,dy\,dz$ |
| 柱面坐标 | $x=\rho\cos\theta,\ y=\rho\sin\theta,\ z=z$ | $\boxed{\rho\,d\rho\,d\theta\,dz}$ |
| 球面坐标 | $x=r\sin\varphi\cos\theta,\ y=r\sin\varphi\sin\theta,\ z=r\cos\varphi$ | $\boxed{r^2\sin\varphi\,dr\,d\varphi\,d\theta}$ |

---

### 8.4 对称性速查

**使用前必须同时确认：区域对称 + 函数奇偶。**

| 区域对称性 | 函数条件 | 结论 |
|-----------|----------|------|
| 关于 $y$ 轴对称 | $f$ 关于 $x$ 是奇函数 | 积分为 $0$ |
| 关于 $x$ 轴对称 | $f$ 关于 $y$ 是奇函数 | 积分为 $0$ |
| 关于两轴都对称 | $f$ 关于 $x,y$ 都是偶函数 | 积分 = $4 \times$ 第一象限 |
| 关于 $xOy$ 平面对称 | $f$ 关于 $z$ 是奇函数（三重） | 积分为 $0$ |

---

### 8.5 结果检查清单

算完后逐条过：

- [ ] **量纲对吗？** 面积应该含长度²，体积含长度³，质量 = 密度 × 体积。
- [ ] **正负合理吗？** 被积函数 ≥ 0 时积分应 ≥ 0。有负值的要检查符号。
- [ ] **对称性用对了吗？** 奇函数在对称区域上积分 = 0，偶函数可折叠。
- [ ] **面积/体积元素因子带了吗？** 极坐标有 $\rho$，球面坐标有 $r^2\sin\varphi$。
- [ ] **积分限常数/变量位置对吗？** 内层限可以含外面变量，外层限必须常数。
- [ ] **$f=1$ 验证：** 二重积分 $f=1$ 结果应该是区域面积；三重积分 $f=1$ 结果应该是体积。

### 8.6 考试高频考点（优先级排序）

| 优先级 | 考点 | 理由 |
|--------|------|------|
| ★★★ | 直角坐标二重积分（X型/Y型） | 基础中的基础，必考 |
| ★★★ | 极坐标二重积分 | 圆/环区域，必考 |
| ★★★ | 交换积分次序 | 高频，套路固定 |
| ★★☆ | 三重积分直角坐标 | 基本计算 |
| ★★☆ | 柱面坐标、球面坐标 | 对称体专用 |
| ★★☆ | 曲面面积、质心、转动惯量 | 应用题 |
| ★☆☆ | 一般换元法（雅可比） | 偶尔考，套路固定 |
| ★☆☆ | 含参变量积分（莱布尼茨） | 偶尔考，偏技巧 |
| ★☆☆ | 引力问题 | 很少考，了解公式即可 |

### 8.7 最后叮嘱

> 这一章内容多，但逻辑线清晰：**切小块求和 → 选坐标 → 写限 → 带元素 → 算**。每种坐标系只是换个方式描述"小块"的大小。考试前两天，把上面的检查清单过一遍，把极坐标和球面坐标的体积元素默写三遍，这两处是最常见的扣分点。
