## 8. 章末总复习：做题检查清单 + 考点地图

### 与上一小节关系

前七节把二重积分、三重积分、坐标变换、应用、含参积分全讲完了。这一节是**考前冲刺用的**——把所有内容压缩成可执行的检查清单，做一道题对一遍。

### 学习目标

- 能一眼判断题目属于哪一类问题。
- 能在开始算之前选对坐标、边界和积分元素。
- 能用结果检查法发现自己的常见错误。

---

### 8.1 题型分类（考试出什么）

本章所有题目都在下面五类里：

| 类型 | 标志 | 核心动作 |
|------|------|----------|
| **二重积分计算** | 被积函数和区域都在 $xy$ 平面 | 画图 → 选坐标 → 写限 → 积 |
| **三重积分计算** | 被积函数和空间体在 $xyz$ 空间 | 画图 → 选坐标 → 写三层限 → 积 |
| **应用题** | 问体积/面积/质量/质心/转动惯量/引力 | 元素法：小块贡献 → 积分 |
| **含参积分** | 积分号里有参数，或积分限含变量 | 求导/换序/莱布尼茨 |
| **理论/证明题** | 估值、比较、中值定理、对称性 | 用性质，不算 |

---

### 8.2 做题标准流程

#### 二重积分

```
画区域
  ↓
看区域形状 + 被积函数
  ├── 圆/环/扇形 或 含 x²+y² → 极坐标
  ├── 椭圆 → 广义极坐标
  ├── 出现 x+y、y/x 等组合 → 一般换元
  └── 一般情况 → 直角坐标
  ↓
选扫描方向（X型 vs Y型）
  ↓
写范围（内层限可含外层变量）
  ↓
带面积元素（直角 dxdy，极坐标 ρdρdθ，换元 |J|dudv）
  ↓
先看对称性！奇函数项直接消掉
  ↓
计算（内层→外层）
```

#### 三重积分

```
画空间体
  ↓
看对称性
  ├── 绕 z 轴对称 → 柱面坐标 (ρdρdθdz)
  ├── 球对称 → 球面坐标 (r²sinφ drdφdθ)
  └── 一般 → 直角坐标
  ↓
选投影方向 或 截面法
  ↓
写三层范围（最内层限可含外面变量）
  ↓
带体积元素
  ↓
计算
```

### 8.3 坐标与积分元素速查

| 坐标系 | 变换公式 | 面积/体积元素 |
|--------|----------|--------------|
| 直角（二重） | $x,y$ | $dx\,dy$ |
| 极坐标 | $x=\rho\cos\theta,\ y=\rho\sin\theta$ | $\boxed{\rho\,d\rho\,d\theta}$ |
| 一般换元 | $x=x(u,v),\ y=y(u,v)$ | $\boxed{\|J\|\,du\,dv}$ |
| 直角（三重） | $x,y,z$ | $dx\,dy\,dz$ |
| 柱面坐标 | $x=\rho\cos\theta,\ y=\rho\sin\theta,\ z=z$ | $\boxed{\rho\,d\rho\,d\theta\,dz}$ |
| 球面坐标 | $x=r\sin\varphi\cos\theta,\ y=r\sin\varphi\sin\theta,\ z=r\cos\varphi$ | $\boxed{r^2\sin\varphi\,dr\,d\varphi\,d\theta}$ |

---

### 8.4 对称性速查

**使用前必须同时确认：区域对称 + 函数奇偶。**

| 区域对称性 | 函数条件 | 结论 |
|-----------|----------|------|
| 关于 $y$ 轴对称 | $f$ 关于 $x$ 是奇函数 | 积分为 $0$ |
| 关于 $x$ 轴对称 | $f$ 关于 $y$ 是奇函数 | 积分为 $0$ |
| 关于两轴都对称 | $f$ 关于 $x,y$ 都是偶函数 | 积分 = $4 \times$ 第一象限 |
| 关于 $xOy$ 平面对称 | $f$ 关于 $z$ 是奇函数（三重） | 积分为 $0$ |

---

### 8.5 结果检查清单

算完后逐条过：

- [ ] **量纲对吗？** 面积应该含长度²，体积含长度³，质量 = 密度 × 体积。
- [ ] **正负合理吗？** 被积函数 ≥ 0 时积分应 ≥ 0。有负值的要检查符号。
- [ ] **对称性用对了吗？** 奇函数在对称区域上积分 = 0，偶函数可折叠。
- [ ] **面积/体积元素因子带了吗？** 极坐标有 $\rho$，球面坐标有 $r^2\sin\varphi$。
- [ ] **积分限常数/变量位置对吗？** 内层限可以含外面变量，外层限必须常数。
- [ ] **$f=1$ 验证：** 二重积分 $f=1$ 结果应该是区域面积；三重积分 $f=1$ 结果应该是体积。

### 8.7 总习题十做题经验总结

#### 化极坐标（第 6 题型）

流程：**边界转极坐标 → 找分界角 → 比大小 → 分段写**

1. 把区域的每条边界都写成 $r = g(\theta)$ 的形式
2. 令两个 $r$ 的表达式相等，解出临界角度（就是射线恰好打在交点上的方向）
3. 在各段角度内**代一个特殊值**，比较谁的 $r$ 更小（更小 = 离原点更近 = 先碰到）
4. 更小的那个作为 $r$ 的上限
5. $\theta$ 的总范围：区域在哪些方向上有东西，$\theta$ 就覆盖哪里（上半平面 → $0$ 到 $\pi$，全平面 → $0$ 到 $2\pi$）

#### 积分方程求 $f$（第 7 题型）

1. 认出 $\iint_D f\,dxdy$ 是**常数**（定积分的值就是个数，不含 $x,y$），设为 $A$
2. 把含 $A$ 的 $f$ 表达式代回 $A = \iint_D f\,dxdy$
3. 常数提出积分：$\iint_D C\,dxdy = C\cdot|D|$（面积）
4. 解关于 $A$ 的方程，回代得 $f$

#### 化三次积分（第 8 题型）

核心：**先投影，再定高度**

1. 把所有面整理成"某变量 = 表达式"
2. 确定谁是上界、谁是下界（对 $z$ 而言：哪个面在上面，哪个在下面）
3. 与 $z$ 无关的面（只含 $x,y$）决定投影区域 $D$
4. 在 $D$ 上按 X 型或 Y 型写 $x,y$ 的范围

#### 三重积分计算（第 9 题型）

**判断区域类型 → 选坐标 → 逐层确定范围**

- 全是平面（一次方程）→ 四面体 → 直角坐标
- 球 → 球坐标，$r$ 的上限就是球面
- 绕某轴旋转体 → 柱坐标（绕哪个轴就用哪个轴的柱坐标）
- 区域关于某面对称 + 被积函数关于对应变量是奇函数 → **直接等于 0**

确定范围的方法（从内往外推）：
1. 最内层变量的上下限从面的方程直接读
2. 要求"上限 ≥ 下限"，反推中间层变量的范围
3. 再从中间层的范围反推最外层

#### 曲面面积（第 11 题型）

公式：$A = \displaystyle\iint_D \sqrt{1 + f_x^2 + f_y^2}\,dxdy$

流程：
1. 把曲面写成 $z = f(x,y)$
2. 求 $f_x$、$f_y$
3. 代入 $\sqrt{1+f_x^2+f_y^2}$
4. 确定投影区域 $D$（曲面在 $xOy$ 平面的影子，令 $z=0$ 找边界）
5. 算二重积分

注意：答案不一定要化到最简，写成 $\sqrt{1+f_x^2+f_y^2}\cdot|D|$ 的形式完全可以得满分。
