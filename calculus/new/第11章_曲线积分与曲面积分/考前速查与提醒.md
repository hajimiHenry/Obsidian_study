# 第11章 考前速查与提醒

## 四类积分怎么算

| 类型 | 识别标志 | 方法 |
|------|---------|------|
| 第一类曲线积分 | $\mathrm{d}s$ | 参数化，$\mathrm{d}s = \sqrt{x'^2+y'^2(+z'^2)}\,\mathrm{d}t$，上限>下限 |
| 第二类曲线积分 | $\mathrm{d}x,\mathrm{d}y$ | 参数化，$\mathrm{d}x=x'(t)\mathrm{d}t$，上下限跟方向走 |
| 第一类曲面积分 | $\mathrm{d}S$ | 投影，$\mathrm{d}S = \sqrt{1+z_x^2+z_y^2}\,\mathrm{d}x\mathrm{d}y$ |
| 第二类曲面积分 | $\mathrm{d}y\mathrm{d}z$ 等 | 投影，上侧取正、下侧取负，无根号 |

---

## 做题决策树

```
拿到第二类曲线积分 ∫ Pdx + Qdy →
  先算 Py 和 Qx
  │
  ├─ 相等 → 路径无关 → 势函数 u(B)-u(A)
  │
  └─ 不等 → 闭曲线？
              ├─ 是 → 格林公式转二重积分
              └─ 否 → 能补线凑闭？
                        ├─ 能 → 补线 + 格林公式 - 补线贡献
                        └─ 否 → 参数化硬算

拿到第二类曲面积分 →
  闭曲面？
  ├─ 是 → 高斯公式（散度→三重积分）
  └─ 否 → 能补面凑闭？
            ├─ 能 → 补面 + 高斯 - 补面贡献
            └─ 否 → 投影法（判正负号）
```

---

## 🔴 格林公式

$$\oint_L P\,\mathrm{d}x + Q\,\mathrm{d}y = \iint_D (Q_x - P_y)\,\mathrm{d}x\,\mathrm{d}y$$

**答题必写**：根据格林公式

**条件**：闭曲线 + 正向（逆时针）+ $P,Q$ 有连续一阶偏导

**注意**：右边是 $Q_x - P_y$，不是 $P_x - Q_y$

---

## 🔴 路径无关

$P_y = Q_x$（单连通区域内）→ 四件事等价：
1. $P_y = Q_x$
2. 闭曲线积分 = 0
3. 路径无关
4. 存在势函数 $u$，$\mathrm{d}u = P\mathrm{d}x + Q\mathrm{d}y$

**求势函数的步骤**：
1. 对 $P$ 关于 $x$ 积分 → $u = F(x,y) + \varphi(y)$
2. 对 $u$ 求 $y$ 偏导，令 $= Q$
3. 解出 $\varphi'(y)$，积分得 $\varphi(y)$

---

## 🔴 高斯公式

$$\oiint_\Sigma P\,\mathrm{d}y\mathrm{d}z + Q\,\mathrm{d}z\mathrm{d}x + R\,\mathrm{d}x\mathrm{d}y = \iiint_\Omega (P_x+Q_y+R_z)\,\mathrm{d}V$$

**答题必写**：根据高斯公式

**条件**：闭曲面 + 外侧 + $P,Q,R$ 有连续一阶偏导

**朝外直接用，朝内加负号**

**补面流程**：求的 = 高斯结果 - 补面贡献

---

## 常见曲面的 $\mathrm{d}S$

| 曲面 | $\mathrm{d}S$ |
|------|------|
| 柱面 $x^2+y^2=R^2$ | $R\,\mathrm{d}\theta\,\mathrm{d}z$ |
| 球面 $x^2+y^2+z^2=R^2$ | $R^2\sin\varphi\,\mathrm{d}\varphi\,\mathrm{d}\theta$ |
| 一般曲面 $z=z(x,y)$ | $\sqrt{1+z_x^2+z_y^2}\,\mathrm{d}x\,\mathrm{d}y$ |

---

## 对称性速判（选择题用）

- 曲面关于某坐标面对称 + 被积函数关于该面为奇 → 积分 = 0
- 被积函数是常数 → $\iint c\,\mathrm{d}S = c\times\text{面积}$，$\iiint c\,\mathrm{d}V = c\times\text{体积}$

---

## 容易忘的点

- 第一类积分与方向无关，第二类积分方向反了变号
- 格林公式右边是 $Q_x - P_y$，路径无关条件是 $P_y = Q_x$，本质一回事
- 补面的正负号：看法向量朝哪（朝上正、朝下负），不是看"朝外"就一定是正
- 空间曲线的 $\mathrm{d}s$ 根号下是**三项**（别漏 $z'^2$）
- 求势函数时，"积分常数"是另一个变量的函数 $\varphi(y)$，不是普通常数
- 闭曲线 = 起点终点相同；开曲线 = 起点终点不同
- $\int_0^{2\pi}\sin t\,\mathrm{d}t = 0$，$\int_0^{2\pi}\cos t\,\mathrm{d}t = 0$，$\int_0^{2\pi}\sin^2t\,\mathrm{d}t = \pi$

## 上学期公式（本章高频用到）

**分部积分**：$\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u$

**一阶线性 ODE**：$y'+py=q$ 的通解：
$$y = e^{-\int p\,\mathrm{d}x}\left(\int q\cdot e^{\int p\,\mathrm{d}x}\,\mathrm{d}x + C\right)$$

**arctan 积分**：$\int\frac{\mathrm{d}x}{a^2+x^2} = \frac{1}{a}\arctan\frac{x}{a}+C$

**半角公式**：$1+\cos t = 2\cos^2\frac{t}{2}$，$1-\cos t = 2\sin^2\frac{t}{2}$
