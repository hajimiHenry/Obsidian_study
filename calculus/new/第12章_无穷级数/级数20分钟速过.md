## 一、基本概念（题 1）

**级数收敛** = 部分和数列 $s_n = u_1+u_2+\cdots+u_n$ 有极限。

**必要条件**：$\lim_{n\to\infty} u_n = 0$（通项趋于零是收敛的**必要**条件，不是充分条件。反例：调和级数 $\sum\frac{1}{n}$，通项趋于零但发散）

**正项级数的特殊性**：部分和单调递增，所以 $\{s_n\}$ 有界 $\iff$ 收敛。这是**充要**条件。

**绝对收敛 vs 条件收敛**：
- 绝对收敛：$\sum|u_n|$ 收敛 → $\sum u_n$ 一定也收敛
- 条件收敛：$\sum u_n$ 收敛但 $\sum|u_n|$ 发散

## 二、正项级数判别法（题 2）🔴

### 2.1 p 级数（必须记住）

$$\sum_{n=1}^{\infty}\frac{1}{n^p} \quad\begin{cases} p > 1 & \text{收敛} \\ p \le 1 & \text{发散} \end{cases}$$

特别：$p=1$ 是调和级数，发散；$p=\frac{3}{2}$ 收敛。

### 2.2 比值审敛法（最常用）

$$\lim_{n\to\infty}\frac{u_{n+1}}{u_n} = \rho$$

- $\rho < 1$ → 收敛
- $\rho > 1$ → 发散
- $\rho = 1$ → 失效，换别的方法

**适用场景**：含 $n!$、$a^n$、$n^n$ 的级数

### 2.3 根值审敛法

$$\lim_{n\to\infty}\sqrt[n]{u_n} = \rho$$

判断标准和比值法一样。

**适用场景**：通项是 $(\text{某东西})^n$ 的形式

### 2.4 比较审敛法

跟已知级数比：
- 比收敛的小 → 收敛
- 比发散的大 → 发散

**极限比较形式**：$\lim\frac{u_n}{v_n} = c$（$0 < c < +\infty$）→ 同敛散

### 2.5 做题选哪个？

| 通项特征 | 用什么 |
|---------|--------|
| 含 $n!$ 或 $a^n$ | 比值法 |
| 整体是 $n$ 次幂形式 | 根值法 |
| 像 $\frac{1}{n^p}$ 的变形 | 比较法，和 p 级数比 |
| $\frac{1}{\ln^k n}$ 这种 | 比较法，它比 $\frac{1}{n}$ 大 → 发散 |

## 三、交错级数 + 绝对/条件收敛（题 3）🔴

### 3.1 莱布尼茨定理

交错级数 $\sum(-1)^{n-1}u_n$（$u_n > 0$），满足：
1. $u_n \ge u_{n+1}$（单调递减）
2. $\lim u_n = 0$

则收敛。

### 3.2 判断绝对/条件收敛的步骤

```
1. 加绝对值，看 Σ|u_n| 是否收敛
   - 收敛 → 绝对收敛（完事）
   - 发散 → 继续第2步
2. 看原级数 Σu_n 是否收敛（用莱布尼茨等）
   - 收敛 → 条件收敛
   - 发散 → 发散
```

### 3.3 常见结论

$$\sum(-1)^n\frac{1}{n^p}\quad\begin{cases} p > 1 & \text{绝对收敛} \\ 0 < p \le 1 & \text{条件收敛} \\ p \le 0 & \text{发散} \end{cases}$$

## 四、幂级数的收敛区间（题 4）🔴

### 4.1 求收敛半径

对 $\sum a_n x^n$，用相邻系数比值：

$$R = \lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right|$$

或根值法：

$$\frac{1}{R} = \lim_{n\to\infty}\sqrt[n]{|a_n|}$$

### 4.2 完整流程

1. 求收敛半径 $R$ → 开区间 $(-R, R)$
2. **单独检查端点** $x = \pm R$：代入后变成常数项级数，逐个判断
3. 写出收敛域（开区间/半开/闭区间）

> **收敛区间** vs **收敛域**：区间不含端点讨论，域包含端点讨论！

### 4.3 注意事项

- $(x+1)^n$ 型：收敛中心在 $x=-1$，先令 $t=x+1$ 再算
- $x^{2n}$ 型：令 $t=x^2$，先对 $t$ 求半径，再开方回 $x$
- 端点常常变成 p 级数或交错级数

## 五、求和函数（题 5、6、7）🔴

### 5.1 核心工具：逐项求导 & 逐项积分

在收敛区间 $(-R, R)$ 内：

$$\left(\sum a_n x^n\right)' = \sum n a_n x^{n-1}$$

$$\int_0^x \sum a_n t^n\,dt = \sum \frac{a_n}{n+1} x^{n+1}$$

### 5.2 做题套路

**如果通项分母有 $n$ 或 $n+1$**：对和函数求导，消掉分母 → 识别出已知级数 → 再积回去

**如果通项分子有 $n$**：对和函数积分，消掉分子的 $n$ → 识别出已知级数 → 再求导回去

### 5.3 必须记住的基本和函数

$$\sum_{n=0}^{\infty} x^n = \frac{1}{1-x}, \quad |x|<1$$

$$\sum_{n=1}^{\infty} n x^{n-1} = \frac{1}{(1-x)^2}, \quad |x|<1$$

$$\sum_{n=1}^{\infty} \frac{x^n}{n} = -\ln(1-x), \quad -1\le x<1$$

$$\sum_{n=0}^{\infty} \frac{x^n}{n!} = e^x, \quad x\in\mathbb{R}$$

> 第一个求导得第二个，第一个积分得第三个。记住第一个，另外两个都能推。

### 5.4 典型操作示范

求 $\sum_{n=1}^{\infty} n x^n$ 的和函数：

$$\sum n x^n = x\sum n x^{n-1} = x\cdot\frac{1}{(1-x)^2} = \frac{x}{(1-x)^2}$$

## 六、函数展开成幂级数（题 8）🔴

### 6.1 常用展开式（必须背）

$$e^x = \sum_{n=0}^{\infty}\frac{x^n}{n!}, \quad x\in\mathbb{R}$$

$$\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n, \quad |x|<1$$

$$\frac{1}{1+x} = \sum_{n=0}^{\infty}(-1)^n x^n, \quad |x|<1$$

$$\ln(1+x) = \sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{n}x^n, \quad -1<x\le1$$

$$\sin x = \sum_{n=0}^{\infty}\frac{(-1)^n}{(2n+1)!}x^{2n+1}, \quad x\in\mathbb{R}$$

$$\cos x = \sum_{n=0}^{\infty}\frac{(-1)^n}{(2n)!}x^{2n}, \quad x\in\mathbb{R}$$

$$(1+x)^\alpha = 1+\sum_{n=1}^{\infty}\frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}x^n, \quad |x|<1$$

### 6.2 间接展开法（最常用）

不用从头算各阶导数，而是把目标函数变形成已知展开式的组合。

**常见操作**：
- 换元：$\frac{1}{2-x} = \frac{1}{2}\cdot\frac{1}{1-\frac{x}{2}}$，然后套 $\frac{1}{1-t}$ 的展开
- 求导后展开：$\frac{1}{(1-x)^2}$ 是 $\frac{1}{1-x}$ 的导数
- 积分后展开：$\ln(1+x) = \int_0^x \frac{1}{1+t}\,dt$，先展开再逐项积分

### 6.3 间接展开的常见操作

- 换元：$\frac{1}{2-x} = \frac{1}{2}\cdot\frac{1}{1-\frac{x}{2}}$，然后套 $\frac{1}{1-t}$ 的展开
- 求导后展开：$\frac{1}{(1-x)^2}$ 是 $\frac{1}{1-x}$ 的导数
- 积分后展开：$\ln(1+x) = \int_0^x \frac{1}{1+t}\,dt$，先展开再逐项积分

## 全章做题决策树

```
拿到一个级数 →
  常数项还是函数项？
  │
  ├─ 常数项（判敛散）→
  │   正项？→ 比值/根值/比较
  │   交错？→ 莱布尼茨
  │   问绝对/条件？→ 先看|u_n|，再看u_n
  │
  └─ 函数项（幂级数）→
      求收敛区间？→ 算R + 查端点
      求和函数？→ 逐项求导/积分 → 凑成已知级数
      展开成幂级数？→ 间接法（变形成已知展开式）
```
