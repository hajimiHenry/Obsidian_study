# 第六章 中华民族的抗日战争（续）

## 中国共产党在抗日战争中的中流砥柱作用（续）

民族抗日武装作战12.5万余次，钳制和歼灭日军大量兵力，歼灭大部分伪军，敌后战场逐渐成为中国人民抗日战争的主战场。

### 4. 不断把党建设成为坚强的领导核心

政治是战争胜负的根本，中国共产党以坚定的政治领导、正确的方向、政治路线，制定正确的战略战术，在政治、军事、战争战略和战略战术方面，坚持全面抗战，开辟敌后战场，建立敌后抗日根据地，使敌后战场逐渐成为中国人民抗日战争的主战场。

**以以上的几点都不断将自身建设成为坚强领导核心的体现，灵活记忆：**

#### 1. 坚持抗战、团结、进步的方针

第一，统一战线中的独立自主原则，抗日民族统一战线是以国共合作为基础的，中国共产党在统一战线中坚持独立自主原则，保持共产党在思想上、政治上和组织上的独立性，放手发动群众，壮大人民力量，坚持统一战线的领导权。这是把抗日民族战争引向胜利的中心环节。

#### 2. 坚持抗战、反对投降，坚持团结、反对分裂，坚持进步、反对倒退

在抗战情况下，民族斗争高于阶级斗争，民族斗争与阶级斗争表现出一致性。

第三，巩固抗日民族统一战线的策略总方针，为了抗日民族统一战线的坚持、扩大和巩固，中国共产党制定了"发展进步势力、争取中间势力、孤立顽固势力"的策略总方针。进步势力是指工人、农民和城市小资产阶级，他们是统一战线的基础、抗日战争的主要依靠力量。中间势力主要是指民族资产阶级、开明绅士和地方实力派。顽固势力是指大地主大资产阶级的抗日派，即以蒋介石集团为代表的国民党亲英美派。他们采取两面政策，既抗日又反共，既联共又反共。因此，共产党必须以革命的两面政策来对付，既要争取他们抗日，又要反对他们的反共。在同顽固派的斗争中，坚持有理、有利、有节的原则。

### 2. 抗日民主根据地的建设

抗战时期，中国共产党的工作重心在敌后发动抗日游击战争，建设抗日民主根据地，同时也在抗日统治区（称大后方）进行促进抗日与民主方面的力量工作。

**政权建设方面，**"三三制"的民主政权建设。抗日民主政府在工作人员分配上实行"三三制"原则，即共产党员、非党的左派进步分子和中间派各占1/3。这样可以容纳各方面的代表，团结一切赞成抗日又赞成民主的阶级、阶层。这是一项团结抗日的很好的政权形式，一定要贯彻执行。

**经济建设方面，**实行减租减息，发展生产。减租减息是中国共产党在抗日根据地内调整土地关系的基本政策，一方面使广大农民减轻了地租和利息的负担，提高了农民参加抗战和生产的积极性；另一方面，农民又交租交息，有利于联合地主阶级一致抗日，实行这个政策既调动了广大农民的抗日积极性，又有利于争取地主阶级的大多数站在抗日民族统一战线一边。为克服根据地面临的严重的经济困难，毛泽东提出了"发展经济，保障供给"的经济工作和财政工作的总方针，发出了"自己动手，丰衣足食"的号召。1942年，中国共产党领导根据地军民开展了大生产运动。抗日根据地实行精兵简政，以减轻人民负担。这些措施为坚持抗战、争取胜利奠定了物质基础。

**文化建设与干部教育方面，**全民族抗战开始后，大批知识青年和革命分子奔赴延安，中共中央及时作出大量吸收知识分子的决定，把开展文化运动作为抗日战争的一项重要任务。创办了中国人民抗日军政大学、鲁迅艺术学院、马列学院等。1940年8月创办的延安自然科学院，是中国共产党历史上第一个开展自然科学教学与研究的专门机构。

### 3. 大后方的抗日民主运动和进步文化工作

全民抗战开始后，各界人民群众要求国民党政府实行民主改革。国民参政会的设立，在客观上也有利于民主人士参与国是、发表政见、提出建议，推动了抗日民主运动的深入发展。

中国的民主政团同盟，1941年3月，在中国民主政团同盟秘密成立。1941年9月创办了《光明报》。

文化界抗日救亡运动蓬勃开展，1938年成立的中华全国文艺界抗敌协会等组织，开展抗日文化工作。

国民党统治区的抗日民主运动和进步文化工作，是中国共产党领导的抗日民族统一战线的重要组成部分。

**"马克思主义的中国化"命题的提出：**1938年9月至11月，在中国共产党六届六中全会上，毛泽东明确提出了"马克思主义的中国化"的命题。全会基本上纠正了王明的右倾错误，进一步巩固了毛泽东在全党的领导地位。统一了全党的思想和步调，推动了各项工作迅速发展。

## 17. 抗日战争的胜利及其原因和意义

### 1. 抗日战争胜利的标志

世界反法西斯战争胜利结束，1945年10月25日，中国政府在台湾举行受降仪式。根据《开罗宣言》、《波茨坦公告》，被日本占领50年之久的台湾以及澎湖列岛，重归中国主权管辖。这成为中国人民抗日战争完全胜利的重要标志。

### 2. 抗日战争胜利的原因

第一，以爱国主义为核心的民族精神是中国人民抗日战争胜利的决定因素。

第二，中国共产党的中流砥柱作用是中国人民抗日战争胜利的关键。

第三，全民族抗战是中国人民抗日战争胜利的重要法宝。

第四，反侵略战争的正义性，得到世界上爱好和平与正义的国家和人民、国际组织以及各种反法西斯力量的同情和支持。

中国共产党始终坚持发动人民、依靠人民，推动建立了抗日民族统一战线，实现全民族抗战，坚持全面抗战路线，开辟敌后战场，进行持久战，使抗日战争成为人民战争汪洋大海中的正义之战，为夺取抗日战争的最后胜利奠定了坚实基础。

第五，中国人民抗日战争的胜利，离不开世界反法西斯统一战线的建立，世界爱好和平与正义的国家和人民、国际组织以及各种反法西斯力量的支持。

### 3. 抗日战争胜利的意义

第一，抗日战争的胜利，彻底粉碎了日本军国主义殖民奴役中国的图谋，洗刷了近代以来中国抗击外来侵略屡战屡败的民族耻辱。

第二，重新确立了中国在世界上的大国地位，使中国人民赢得了世界爱好和平人民的尊敬。

第三，开辟了中华民族伟大复兴的光明前景，人民民族意识进一步觉醒，为中国共产党带领中国人民实现彻底的民族独立和人民解放奠定了重要基础。

### 4. 中国人民抗日战争在世界反法西斯战争中的地位

（有可能考到简答题：2条）

第一，中国抗日战争是世界反法西斯战争的重要组成部分，是世界反法西斯战争的东方主战场。中国的抗日战争为世界反法西斯战争的胜利作出了巨大贡献。全世界有4/5的陆地被卷入战争，世界上绝大多数国家和人民、反法西斯同盟国的军队和人民直接或间接地参加了反法西斯战争。在太平洋战争爆发前，中国是抗击日本的唯一国家。中国战场作为世界反法西斯战争的东方主战场，牵制和抗击了日本军国主义的主要兵力。中国战场牵制和抗击了日军总兵力的2/3以上，粉碎了日本"速战速决"的战略企图。

第二，世界反法西斯力量对中国的援助，中国人民抗日战争的胜利，是同世界爱好和平与正义的国家和人民、国际组织以及各种反法西斯力量的同情和支持分不开的。

# 第七章 为建立新中国而奋斗

## 18. 解放战争时期，中国各种政治势力的三种建国方案

1949年新中国成立前，在解放战争时期，中国社会存在三种不同的建国主张和政治力量。以国共两党为代表的两种政治力量展开了决定中国命运的决战。这三种建国方案是：

第一种是国民党统治集团所主张的地主阶级和大资产阶级专政的建国方案，他们是要继续走半殖民地半封建社会的道路。人民民主专政的人民共和国。

第二种是中国共产党提出的人民民主专政的建国方案，即建立工人阶级领导的、以工农联盟为基础的、团结一切革命阶级的人民民主专政的共和国，即人民民主专政的人民共和国，这是中国人民在共产党领导下 New民主革命的基本政治纲领。

第三种是某些中间派或中间人士主张的资产阶级共和国方案，即建立一个资产阶级专政的资本主义国家，实际上，是旧中国民族资产阶级的阶级利益和要求的反映，是一种资产阶级共和国的方案。

国民党政权的灭亡，由于国民党统治集团代表地主阶级和大资产阶级的利益，实行独裁统治和内战政策，必然遭到全国人民的坚决反对。中国共产党领导的人民革命力量经过解放战争，终于推翻了国民党的反动统治。

中国共产党领导的新民主主义革命的胜利，使中国社会发生了翻天覆地的变化。中国人民从此站起来了，中国历史进入了一个新纪元。

## 19. 国民党失败的原因和中国共产党胜利的基本经验

### 1. 国民党失败的原因

国民党政权的灭亡，从根本上说，是由国民党政权的反动本质决定的。国民党统治集团为了维护帝国主义、封建主义和官僚资本主义的利益，实行独裁统治，发动反共反人民的内战，最终失去了人民的支持，必然走向失败。

### 2. 中国共产党胜利的原因

第一，中国革命的发生和发展有着深刻的社会根源和雄厚的群众基础。由于帝国主义的侵略和压迫，由于封建主义和官僚资本主义的压迫，中国人民生活极端痛苦。中国人民在反帝反封建的斗争中，工人阶级是新的社会力量，农民阶级是革命的主力军，城市小资产阶级是可靠的同盟军，民族资产阶级也有一定的革命性。

第二，中国革命之所以能够走上胜利发展的道路，是由于有了中国工人阶级的先锋队——中国共产党的领导。中国共产党作为工人阶级的政党，不仅代表着中国工人阶级的利益，而且代表着中国广大人民和整个中华民族的利益。中国共产党以马克思主义为指导，善于把马克思主义基本原理同中国革命具体实践相结合，制定出正确的路线、方针、政策。

第三，中国革命之所以能够赢得胜利，同国际无产阶级和人民群众的支持分不开。

### 3. 中国革命胜利的意义

第一，中国革命的胜利，结束了中国近代半殖民地半封建社会的历史，实现了民族独立和人民解放，实现了中国从几千年封建专制政治向人民民主的伟大飞跃。

第二，中国革命的胜利，从根本上改变了中国社会的发展方向，为实现由新民主主义向社会主义的过渡、并在社会主义道路上实现中华民族的伟大复兴，创造了前提，开辟了道路。

第三，中国革命的胜利，冲破了帝国主义的东方战线，极大地改变了世界政治力量的对比，鼓舞和推动了世界被压迫民族和被压迫人民争取解放的斗争，对世界历史的发展产生了巨大影响。

第四，中国革命的胜利，是马克思列宁主义、毛泽东思想的胜利，是中国共产党把马克思主义基本原理同中国革命具体实践相结合的胜利。

### 4. 中国革命胜利的基本经验

第一，中国革命的胜利，首先是依靠党领导人民开展武装斗争。中国共产党在长期的武装斗争中，积累了丰富的经验，形成了一套完整的人民战争的战略战术。中国革命的主要斗争形式是武装斗争，主要组织形式是军队。中国共产党创建了人民军队，开展游击战争，实行人民战争的战略战术。

第二，中国革命的胜利，是建立在广泛的统一战线基础之上的。中国共产党领导建立了最广泛的革命统一战线，团结了一切可以团结的力量，孤立和打击了最主要的敌人。统一战线是中国革命胜利的重要法宝。

第三，中国革命的胜利，是加强党的自身建设的结果。中国共产党坚持思想建设、组织建设、作风建设，保持党的先进性和纯洁性，增强党的凝聚力和战斗力。

第四，中国革命的胜利，是马克思列宁主义、毛泽东思想指导的结果。中国共产党坚持以马克思主义为指导，把马克思主义基本原理同中国革命具体实践相结合，形成了毛泽东思想，指导中国革命取得了胜利。

近代中国的历史表明，中国的先进分子从各种救国方案中，最终选择了马克思主义作为救国的思想武器。马克思主义与中国工人运动相结合，产生了中国共产党。中国共产党领导中国人民经过艰苦卓绝的斗争，终于取得了新民主主义革命的胜利，建立了新中国。
