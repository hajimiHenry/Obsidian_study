# Obsidian Study Notes

这是一个个人学习资料仓库，用来集中保存课程笔记、复习材料、图示、讲义整理和阶段性学习规划。

仓库内容以 Markdown 笔记为主，也包含课程 PDF、实验文档、图片素材和部分用于生成图示的脚本。主要目标是让不同设备之间同步学习资料，而不是同步 Obsidian 的本地外观、主题、插件状态。

## 目录结构

- `calculus/`：高等数学笔记，包含章节化讲义、图示、Asymptote/脚本生成的辅助图片。
- `mathematical_logics/`：数理逻辑笔记、章节重构版、题单和形式证明实操材料。
- `linear_algebra/`：线性代数讲义整理。
- `circuit/`：电路课程 PPT、讲义 PDF、实验资料和相关图片。
- `term_planning/`：课表、培养方案、成绩截图等学期规划资料。
- 根目录零散 `.md` / `.txt`：临时整理、OCR 结果、提示词备份或阶段性材料。

## 使用方式

可以直接用 Obsidian 打开本仓库作为 vault，也可以在普通 Markdown 编辑器中阅读。

建议重点维护课程内容目录，例如 `calculus/`、`mathematical_logics/`、`linear_algebra/`。新增课程资料时，优先放入对应学科目录；临时文件整理完成后再移动到正式位置。

## Git 维护约定

- 学习内容、笔记、讲义整理、题单、图示和生成图示所需脚本可以提交。
- Obsidian 本地配置不提交，包括主题、外观、插件、工作区状态和插件数据。
- `.obsidian/` 已加入 `.gitignore`，用于避免把本机 Obsidian 环境同步到仓库。
- 提交前建议先看一眼 `git status`，确认没有把本地配置、缓存或临时文件混进学习资料提交。

## 说明

这个仓库更像学习工作台，不追求目录一开始就完美。真正重要的是保留可复习、可迁移、可继续整理的内容；本地工具配置则留在各自设备上。
