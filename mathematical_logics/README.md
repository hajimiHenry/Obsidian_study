# 数理逻辑资料目录

这个目录已经按资料来源和用途归档，根目录只保留索引和分类文件夹。

## 目录说明

- `01_重构旧版/`：较早一版重构教材，Markdown 格式，第 1-7 章。
- `02_重构新版/`：已经单独成文件夹的新版重构教材，以及阅读友好版本。
- `03_练习题单/`：期中模拟题单和专项练习。
- `04_解题套路/`：命题逻辑、一阶逻辑等证明与推理套路。
- `05_原始文件/`：课程 PDF、PPTX 原始文件。
- `06_复习总览/`：总复习课件和知识图谱 canvas。

## 建议使用顺序

1. 先看 `02_重构新版/`，作为主要复习材料。
2. 遇到不熟或需要对照的章节，再看 `01_重构旧版/`。
3. 需要核对来源内容时，再打开 `05_原始文件/`。
4. 做题前看 `04_解题套路/`。
5. 最后用 `03_练习题单/` 和 `06_复习总览/` 检查掌握情况。
