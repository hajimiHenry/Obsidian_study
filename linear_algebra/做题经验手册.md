> 按章节顺序整理，边做题边积累，考前快速翻阅用。

## 知识串联（一条主线）

```
矩阵运算 → 逆矩阵 → 矩阵方程（用逆来解）
              ↓
         伴随矩阵（逆的另一种表达）
              ↓
         行变换（求逆的工具）→ 求秩（数非零行）
                                    ↓
                              方程组解的判定（秩 vs 未知数个数）
                                    ↓
                              向量组的线性相关性（本质就是方程组有没有非零解）
```

> 一句话：**所有东西的底层操作都是行变换**，不同章节只是在不同场景下使用它。

# 第二章：矩阵及其运算

## 一、逆矩阵

### 方法选择

| 矩阵类型 | 最快方法 |
|---|---|
| 2 阶 | 公式法：$A^{-1} = \frac{1}{ad-bc}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$（主对角互换，副对角变号） |
| 3 阶及以上 | 初等行变换：$(A\mid E) \to (E\mid A^{-1})$ |
| 对角阵 $\mathrm{diag}(a_1,\dots,a_n)$ | 各元素取倒数 |
| 分块对角阵 $\begin{pmatrix} A_1 & O \\ O & A_2 \end{pmatrix}$ | 各块分别求逆 |
| 分块副对角阵 $\begin{pmatrix} O & A \\ B & O \end{pmatrix}$ | $\begin{pmatrix} O & B^{-1} \\ A^{-1} & O \end{pmatrix}$ |

### 行变换固定流程（不需要灵感）

1. 从第 1 列开始，把主元位置变成 1，用它消掉**下方**所有行
2. 第 2 列同理
3. 全部化成阶梯形后，**从下往上回消**，消掉每列主元上方的数
4. 左边变成 $E$，右边就是 $A^{-1}$

口诀：**先下三角（阶梯形），再上三角（回消）。每步只做"让某个位置变 0"这一件事。**

---

## 二、伴随矩阵

### 核心公式（就这一个，其他全是推论）

$$AA^* = A^*A = |A|E$$

### 常用推论

| 公式 | 使用场景 |
|---|---|
| $A^* = \|A\|A^{-1}$ | 把 $A^*$ 转化成 $A^{-1}$ 来统一计算 |
| $A = \|A\|(A^*)^{-1}$ | 已知 $A^*$ 反推 $A$ |
| $\|A^*\| = \|A\|^{n-1}$ | 求伴随矩阵的行列式 |
| $(cA)^{-1} = \frac{1}{c}A^{-1}$ | 数乘矩阵的逆 |

### 行列式 vs 矩阵的"提系数"区别（易错）

$$|cA| = c^n|A| \quad (\text{行列式提系数要}n\text{次方})$$

$$cA \text{ 就是每个元素乘 } c \quad (\text{矩阵提系数没有次方问题})$$

### 典型题路线（题 16 类型）

目标：化简含 $A^*, A^{-1}$ 的表达式再求行列式。

1. 用 $A^* = |A|A^{-1}$ 把所有东西统一成 $A^{-1}$ 的倍数
2. 合并同类项得到 $cA^{-1}$
3. 用 $|cA^{-1}| = c^n \cdot |A|^{-1}$ 算出数值

## 三、矩阵方程

### 核心：识别形式，用逆矩阵剥离 $X$

| 形式 | 解法 |
|---|---|
| $AX = B$ | $X = A^{-1}B$（左乘逆） |
| $XA = B$ | $X = BA^{-1}$（右乘逆） |
| $AXB = C$ | $X = A^{-1}CB^{-1}$ |

> ⚠️ **矩阵乘法不能交换顺序**，$A^{-1}B \neq BA^{-1}$。

### 复杂方程的处理

遇到含 $A^*, BA, A^{-1}$ 等混合的方程：
1. 先用 $A^* = |A|A^{-1}$ 统一符号
2. 把含未知矩阵的项归到一边，提公因子
3. 逐步剥离：先解出 $BA$（或 $BA^{-1}$），再右乘 $A^{-1}$（或 $A$）得到 $B$

---

## 四、利用多项式条件证明可逆 + 求逆

### 题型特征

给你 $f(A) = O$（如 $A^2 - A - 2E = O$），让你证明某个矩阵可逆。

### 统一套路

**证明可逆 = 找到逆**，两件事同时完成。

1. 把等式移项/因式分解，凑成 $(\text{目标矩阵}) \cdot (\text{某矩阵}) = cE$
2. 两边除以 $c$，按定义那个"某矩阵/$c$"就是逆

### 例子

| 条件 | 凑法 | 结果 |
|---|---|---|
| $A^2 - A - 2E = O$ 证 $A$ 可逆 | $A(A-E) = 2E$ | $A^{-1} = \frac{1}{2}(A-E)$ |
| 同上，证 $A+2E$ 可逆 | 直接 $A+2E = A^2$，取逆 | $(A+2E)^{-1} = (A^{-1})^2$ |
| $A^k = O$ 证 $E-A$ 可逆 | $(E-A)(E+A+\cdots+A^{k-1}) = E$ | 直接乘出来验证 |

> 捷径：如果条件能直接得到 $\text{目标} = A^n$ 的形式，取逆比配凑因式分解更简单。

## 五、矩阵幂次

### 方法选择

| 类型 | 方法 |
|---|---|
| 能找规律的（如 $\begin{pmatrix}1&0\\\lambda&1\end{pmatrix}$） | 算 $A^2, A^3$ 找规律，归纳 |
| $A^2 = cA$（秩为 1 常见） | $A^k = c^{k-1}A$ |
| $A^2 = E$ | $A^{2k}=E,\ A^{2k+1}=A$ |
| 可对角化 | $A = P\Lambda P^{-1} \Rightarrow A^k = P\Lambda^k P^{-1}$ |

### 秩 1 矩阵的幂（$A = ab^T$）

$$A^2 = (ab^T)(ab^T) = a(b^Ta)b^T = (b^Ta)A$$

设 $c = b^Ta$（一个数），则 $A^k = c^{k-1}A$。

---

## 六、对称与反对称

### 证明技巧

要证 $M$ 对称：算 $M^T$，看是否等于 $M$。

转置规则：$(AB)^T = B^TA^T$（**反序**）

### 常见结论

- $A$ 对称 $\Rightarrow$ $B^TAB$ 对称
- $A, B$ 都对称 $\Rightarrow$ $AB$ 对称 $\iff$ $AB = BA$
- $A, B$ 都反对称 $\Rightarrow$ $AB$ 反对称 $\iff$ $AB = -BA$

# 第三、四章：方程组、秩与向量组

## 七、解方程组——唯一解 vs 通解

### 判断标准

| 情况 | 结果 |
|---|---|
| $R(A) \neq R(\bar{A})$ | 无解 |
| $R(A) = R(\bar{A}) = n$（未知数个数） | **唯一解**，直接回代出数值 |
| $R(A) = R(\bar{A}) < n$ | 有自由变量，写通解 |

> 唯一解时不需要写"通解 = 特解 + 齐次通解"，直接给数值答案。

### 齐次 $Ax=0$ 流程

```
写矩阵 → 行化简 → 数主元(=r) → 自由变量个数 = n-r
→ 用自由变量表示主元变量
→ 自由变量轮流取1其余取0
→ 得到基础解系
→ 通解 = c₁ξ₁ + c₂ξ₂ + ...
```

### 非齐次 $Ax=b$ 流程

```
写增广矩阵(A|b) → 行化简
→ 判有解：R(A)=R(A|b)?
→ 有解 → 自由变量全取0 → 得特解 η*
→ 去掉常数（右边变0）→ 解对应齐次 → 得基础解系
→ 通解 = η* + c₁ξ₁ + c₂ξ₂ + ...
```

### 易错点

- 无解标志：阶梯形出现 $(0\ 0\ \cdots\ 0\ |\ \text{非零})$
- 特解 η* 不属于基础解系（它满足 $Ax=b$，基础解系满足 $Ax=0$）
- 基础解系向量个数 = $n - r$

---

## 八、求秩 / 最大无关组

### 操作

1. 向量排成矩阵（向量当列）
2. 行化简到阶梯形
3. 主元个数 = 秩
4. 主元所在**列号**对应的**原向量** = 最大无关组

### 省计算技巧

- **先观察比例关系**：动笔前先扫一眼，$\alpha_3 = -2\alpha_1$ 能直接看出来
- 求表示系数：化到**简化阶梯形**，非主元列的数值直接就是系数

### 易错点

- **回原矩阵取向量**，不是取化简后的列
- 最大无关组不唯一，但个数（秩）唯一

---

## 九、线性相关 / 无关

### 核心判据

$$R(A) = m \Rightarrow \text{无关}, \quad R(A) < m \Rightarrow \text{相关}$$

### 快捷判断（先过一遍）

| 条件 | 结论 | 原因 |
|---|---|---|
| 向量个数 > 维数 | 直接相关 | $R \leq n < m$ |
| 含零向量 | 直接相关 | 零向量系数随便取 |
| 2 个向量 | 看比例 | 成比例相关，否则无关 |
| $n$ 个 $n$ 维（方阵） | 算行列式 | $|A|\neq0$ 无关 |

### "无关"定义当工具用

已知 $\alpha_1, \alpha_2$ 无关，看到 $(\text{表达式}_1)\alpha_1 + (\text{表达式}_2)\alpha_2 = 0$，直接断言两个表达式都 $= 0$。

---

## 十、向量组的线性表示

### 核心判据

$b$ 能由 $a_1,\dots,a_m$ 表示 $\iff$ $Ax=b$ 有解 $\iff$ $R(A)=R(A|b)$

### 操作

1. 拼增广矩阵 $(A|b)$
2. 行化简
3. $b$ 列有没有出现新主元：没有→能表示，有→不能

### 证明等价

$R(A) = R(B) = R(A,B)$ → 两组向量互相表示 → 等价

---

## 十一、带参数的题

### 方法选择（重要）

| 条件 | 方法 | 原因 |
|---|---|---|
| **方阵** + 参数 | **行列式 = 0** | 不会漏解 |
| **非方阵** / 问秩 | **行化简** | 没有行列式可用 |

> ⚠️ 方阵带参数别用行化简：消元要除以含参数的表达式，忘了检查 $=0$ 的情况就会漏解。

---

## 十二、公共解 / 反向求方程组

### 公共解

两个方程组合在一起当成一个大方程组来解。

### 已知基础解系 → 求方程组

1. 把 $\xi_1^T, \xi_2^T, \dots$ 当行排成矩阵 $B$
2. 解 $Bx = 0$
3. 每个解向量就是原方程组的一行系数

---

## 十三、做题习惯

1. 动笔前先看有没有秒判条件（向量数>维数？含零？比例？）
2. 行化简时每步只做一个操作，别贪多出错
3. 写答案时特征向量带 "$k\neq0$"，通解带 "$c$ 为任意常数"
4. 证明题写清每步用了什么条件

---

# 第五章：特征值、特征向量与相似对角化

## 十四、特征值与特征向量

### 标准流程（不要乱跳步）

1. 求特征方程 $|A - \lambda E| = 0$
2. 解出特征值 $\lambda_1, \lambda_2, \dots$
3. 分别代入 $(A - \lambda_i E)x = 0$
4. 对每个 $\lambda_i$ 解出基础解系
5. 基础解系的非零线性组合就是该特征值的全部特征向量

### 两个速算性质（选择/填空神器）

| 性质 | 公式 | 用途 |
|---|---|---|
| 特征值之和 = 迹 | $\lambda_1 + \lambda_2 + \cdots + \lambda_n = a_{11} + a_{22} + \cdots + a_{nn}$ | 已知两个特征值求第三个 |
| 特征值之积 = 行列式 | $\lambda_1 \lambda_2 \cdots \lambda_n = \|A\|$ | 判断可逆性（有特征值0则不可逆） |

### 常见坑

| 坑 | 正确做法 |
|---|---|
| 特征向量写成了零向量 | 答案必须补 $k \neq 0$ |
| 重特征值就以为有多个特征向量 | 不一定！要实际解 $(A-\lambda E)x=0$ 看基础解系个数 |
| 一上来就解 $Ax = \lambda x$ | 标准路线：先 $\|A-\lambda E\|=0$ 定 $\lambda$，再解 $x$ |

### 关键定理

> **不同特征值对应的特征向量一定线性无关。**

推论：$n$ 阶矩阵有 $n$ 个不同特征值 → 一定可对角化。

---

## 十五、相似对角化

### 核心条件

$$A \text{ 可相似对角化} \iff A \text{ 有 } n \text{ 个线性无关的特征向量}$$

### 判定流程

1. 求所有特征值
2. 对每个 $k$ 重特征值 $\lambda_i$，解 $(A - \lambda_i E)x = 0$
3. 如果基础解系向量个数 $= k$（即 $n - r(A - \lambda_i E) = k$），则该特征值"够用"
4. 所有特征值都够用 → 可对角化

### 快速判断

| 情况 | 结论 |
|---|---|
| $n$ 个不同特征值 | **必可**对角化 |
| 有重根，但每个重根的特征向量数 = 重数 | 可对角化 |
| 某个 $k$ 重根只有 $< k$ 个无关特征向量 | **不可**对角化 |
| 实对称矩阵 | **必可**对角化（而且可正交对角化） |

### 重特征值的关键公式

$$\text{特征向量个数} = n - r(A - \lambda E)$$

题目说"$A$ 可对角化"并给了重特征值 → 立即联想：

$$n - r(A - \lambda E) = \text{该特征值的重数}$$

### 对角化后能干什么

$$A = PDP^{-1} \Rightarrow A^k = PD^k P^{-1}$$

其中 $P$ 的列就是特征向量排成的矩阵，$D$ 是对应特征值的对角阵。

> 求 $A^{100}$ 这类题 → 先对角化。

---

## 十六、正交矩阵与施密特正交化

### 正交矩阵判定

$$A^T A = E \iff \text{列向量两两正交，且每列长度为 } 1$$

快速验证步骤：
1. 先算**某一列的长度**，如果不为 1 → 直接不是
2. 再算**两列点积**，如果不为 0 → 直接不是
3. 全部通过 → 是正交矩阵

### 施密特正交化公式

$$u_1 = a_1$$

$$u_2 = a_2 - \frac{(a_2, u_1)}{(u_1, u_1)} u_1$$

$$u_3 = a_3 - \frac{(a_3, u_1)}{(u_1, u_1)} u_1 - \frac{(a_3, u_2)}{(u_2, u_2)} u_2$$

单位化：

$$e_i = \frac{u_i}{\|u_i\|}$$

### 操作口诀

> 每一步都是：**新向量 = 原向量 − 在已有正交基上的投影**

### 正交对角化流程（实对称矩阵专用）

1. 求特征值
2. 求各特征值的特征向量
3. **不同特征值的特征向量已经正交**（实对称的性质）
4. **同一特征值内**的特征向量做施密特正交化
5. 全部单位化 → 得正交矩阵 $P$
6. $P^{-1}AP = P^TAP = D$

---

## 十七、向量内积相关题型

### 正交分解

已知 $a, b$，要把 $b$ 分解为 $b = \lambda a + c$，其中 $c \perp a$：

$$\lambda = \frac{b \cdot a}{a \cdot a}$$

$$c = b - \lambda a$$

### 正交单位向量组的性质

如果 $a_1, a_2, a_3$ 是标准正交基，$b_i$ 是它们的线性组合，要判断 $b_1, b_2, b_3$ 是否仍正交：

> 只需看**系数向量**是否两两正交且长度为 1。
